# HYGGE 自動ブログシステム セットアップ手順書

村中さんが手動で行う作業のチェックリストです。上から順に進めてください。
各ステップで「控える」と書いてある値は、あとで**スクリプトプロパティ**に入れるのでメモしておいてください。

---

## 成果物の対応表

| ファイル | 置き場所 | 役割 |
|---|---|---|
| `blog/index.html` | GitHubリポジトリ（Vercel公開） | お役立ち情報ハブ（記事一覧） |
| `blog/detail.html` | GitHubリポジトリ（Vercel公開） | 記事詳細ページ |
| `blog-system/Code.gs` | GASプロジェクトに貼り付け | 記事生成＋API＋管理画面のロジック |
| `blog-system/admin.html` | GASプロジェクトにHTMLファイルとして追加（ファイル名 `admin`） | スマホ用の公開管理画面 |

> ⚠️ `blog-system/Code.gs` は**ブログ専用の新しいGASプロジェクト**に貼ります。既存の定休日カレンダー用 `Code.gs` とは別プロジェクトです（混ぜない）。

---

## STEP 1｜スプレッドシートを作る

1. Googleスプレッドシートを新規作成
2. シート名（左下のタブ）を **「ブログ記事」** に変更
3. URL `https://docs.google.com/spreadsheets/d/【ここがID】/edit` の **ID を控える**

➡️ 控える：`SPREADSHEET_ID`

---

## STEP 2｜Driveに画像フォルダを作る（カテゴリ別）

1. Googleドライブに **「HYGGEブログ画像」** フォルダを作成
2. その中に**サブフォルダを5つ**作成：

   | フォルダ名 | 入れる写真 | 控えるプロパティ名 |
   |---|---|---|
   | `sodatekata` | 育て方・季節管理の写真（prod-系など） | `PHOTO_FOLDER_SODATEKATA` |
   | `kazarikata` | 飾り方・インテリアの写真（case-系・shop-系） | `PHOTO_FOLDER_KAZARIKATA` |
   | `diy` | DIY・鉢カバー・ハンギングの写真 | `PHOTO_FOLDER_DIY` |
   | `zakka` | 雑貨・器の写真 | `PHOTO_FOLDER_ZAKKA` |
   | `generated` | （空でOK）GPT生成画像の保存先 | `GENERATED_FOLDER_ID` |

3. 各フォルダを開き、URL `https://drive.google.com/drive/folders/【ここがID】` の **ID をそれぞれ控える**
4. `sodatekata`〜`zakka` に、手持ちの実写真（shop-系・prod-系・case-系）をカテゴリごとに振り分けて入れておく

> 実写真が入っていればそれが優先的にアイキャッチに使われ、空のカテゴリだけAIが画像を生成します。

➡️ 控える：上記5つのフォルダID

---

## STEP 3｜GASプロジェクトを作る

1. [script.google.com](https://script.google.com) →「新しいプロジェクト」
2. デフォルトの `コード.gs` に、`blog-system/Code.gs` の中身を**全部貼り付け**
3. 左メニューの「＋」→「HTML」で新規HTMLファイルを作成し、名前を **`admin`**（拡張子なし）にする
4. その `admin.html` に、`blog-system/admin.html` の中身を**全部貼り付け**て保存

---

## STEP 4｜APIキー等をスクリプトプロパティに設定（★重要・ベタ書き禁止）

GASの左メニュー **⚙️プロジェクトの設定 → スクリプト プロパティ → プロパティを追加** で、以下を1つずつ登録します。

| プロパティ名 | 値 |
|---|---|
| `SPREADSHEET_ID` | STEP1のID |
| `CLAUDE_API_KEY` | Claude APIキー（console.anthropic.com） |
| `OPENAI_API_KEY` | OpenAI APIキー（platform.openai.com） |
| `GENERATED_FOLDER_ID` | STEP2の `generated` フォルダID |
| `PHOTO_FOLDER_SODATEKATA` | STEP2の `sodatekata` ID |
| `PHOTO_FOLDER_KAZARIKATA` | STEP2の `kazarikata` ID |
| `PHOTO_FOLDER_DIY` | STEP2の `diy` ID |
| `PHOTO_FOLDER_ZAKKA` | STEP2の `zakka` ID |
| `LINE_CHANNEL_ACCESS_TOKEN` | STEP5で発行（後で追加でOK） |
| `NOTIFY_USER_ID` | STEP6で取得（後で追加でOK） |
| `ADMIN_KEY` | 管理画面URLの合言葉。推測されにくいランダム文字列を自分で決める（例：`hygge-a8f3k2`） |
| `AUTO_PUBLISH` | `false`（チェックしてから公開）。`true`にすると生成後すぐ自動公開 |
| `WEBAPP_URL` | STEP7のデプロイURL（後で追加） |

> 設定できているか不安なときは、GASで関数 `listRequiredProps` を実行するとログに ✅／⛔ が出ます。

---

## STEP 5｜LINE公式アカウントの Messaging API を用意

※ **LINE Notify は 2025年3月で終了**したため使いません。HYGGE公式アカウントから通知を送ります。

1. [LINE Developers](https://developers.line.biz/) にログイン
2. HYGGE公式アカウントを **Messaging APIチャネル**として利用できるようにする
   （LINE公式アカウントマネージャーの「設定 → Messaging API」から連携も可）
3. **チャネルアクセストークン（長期）** を発行して控える
   → スクリプトプロパティ `LINE_CHANNEL_ACCESS_TOKEN` に設定

---

## STEP 6｜増田さんの userId を取得（通知先の登録）

通知を「増田さん個人」に届けるため、増田さんのLINE userId を1回だけ取得します。

1. GASを一度デプロイする（STEP7を先に実施）。そのWebApp URLをコピー
2. LINE Developers のチャネル設定 → **Webhook URL** に、そのWebApp URLを貼り、**Webhookの利用をON**
3. 増田さんに、HYGGE公式アカウントを友だち追加してもらい、**トークで何か一言送ってもらう**（例：「テスト」）
4. GASで関数 `showLatestUserId` を実行 → ログに出た userId を控える
5. その値をスクリプトプロパティ `NOTIFY_USER_ID` に設定
6. （任意）通知運用が始まったら、Webhook URLは付けたままでOK（userIdは `_userid` シートにも記録されます）

---

## STEP 7｜デプロイして公開する

1. GAS右上 **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**
2. 設定：**実行するユーザー＝自分／アクセスできるユーザー＝全員**
3. デプロイ → 表示された **ウェブアプリURL をコピー**
4. そのURLを次の3か所に設定：
   - スクリプトプロパティ `WEBAPP_URL`
   - `blog/index.html` の `const GAS_API_URL = '【デプロイ後に記入】';`
   - `blog/detail.html` の `const GAS_API_URL = '【デプロイ後に記入】';`（index.htmlと同じURL）

> コードを修正して再反映するときは、毎回「デプロイの管理 → 編集 → バージョン：新規」で更新してください。

---

## STEP 8｜LINE URL をボタンに反映

`blog/index.html`・`blog/detail.html`（およびトップページ `index.html`）の
`#LINE_URL_HERE` を、HYGGEの**友だち追加URL**（例：`https://lin.ee/xxxxxx`）に置き換える。

---

## STEP 9｜GitHubにpush → Vercel公開

1. GitHub Desktopで変更を **commit → push**
2. Vercelが自動でデプロイ
3. LINEリッチメニュー「緑やDIYのお役立ち情報」ボタンの遷移先を
   `https://（HYGGEのドメイン）/blog/` に設定
4. 管理画面URL `【WEBAPP_URL】?page=admin&key=【ADMIN_KEY】` を、増田さんにLINEトークでピン留めしてもらう

---

## STEP 10｜スプレッドシート初期化 & トリガー設定

1. GASで `setupSpreadsheet` を実行 → ヘッダー8列（…＋カテゴリ）が入る
2. GASで `setWeeklyTriggers` を実行 → 火・金 9:00 の自動生成トリガーが2本作られる

## 運用の流れ（設定後）

```
火・金 9:00 → GASが記事＋画像を自動生成（未公開）
        ↓
増田さんのLINEに通知が届く
        ↓
通知のリンクから管理画面を開く（スマホ）
        ↓
プレビューで確認 → 「公開する」をタップ
        ↓
blog/index.html に即反映
```

> チェックが面倒になったら、スクリプトプロパティ `AUTO_PUBLISH` を `true` にすれば、生成後そのまま自動公開に切り替わります（通知は「公開しました」に変わります）。

## 注意事項

- APIキー・トークンは**絶対にGitHubにpushしない**（GASのスクリプトプロパティのみ）
- もしキーをチャットやコードに貼ってしまったら、すぐ再発行する
- Claudeモデルは `claude-sonnet-4-6`、画像は `gpt-image-1`
- サイトに反映されない時は、GASの**再デプロイ漏れ**か、fetchの `redirect:'follow'`（コード済み）を確認
- 画像が出ない時は Drive URL 形式の問題（`toImgUrl()` で変換済み）
